# QuickNotes

QuickNotes is a lightweight note-taking web app for capturing short thoughts and organizing them into Personal, Work, or Study categories. Notes can be searched as you type, deleted individually, and saved in the browser so they remain available after a refresh.

## Features

- Add notes with Personal, Work, and Study categories
- Validate empty notes and notes longer than 200 characters
- Display readable creation dates and note counts
- Search notes without case-sensitive matching
- Delete individual notes
- Persist notes with `localStorage`
- Responsive layout for mobile screens

## Run locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

No build tools or dependencies are required.
